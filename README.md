> Max-Sharpe portfolio studio for India. No sign-up. No data leaves your device.

## What this is

Browser-only portfolio analysis tool. Answer a questionnaire → get an allocation across equity, international ETFs, gold, REITs and P2P. See past and projected performance, honest downside of every assumption, and how each rupee compounds over time. Data refreshed nightly via GitHub Actions scrape.
